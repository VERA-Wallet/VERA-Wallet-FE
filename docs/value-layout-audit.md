# 금액·주소 표시 레이아웃 점검

## 원인과 처리

| 위치 | 넘침 원인 | 처리 |
| --- | --- | --- |
| 리포트 요약 | 3열 고정 카드와 줄바꿈 없는 금액 | 내용 폭에 따른 카드 줄바꿈, 전체 금액 표시 |
| 리포트 상세·비교·계산 근거·VC 결과 | 좌우 항목의 최소 폭 또는 고정 폭 | 값의 최소 폭 해제, 필요 시 행 줄바꿈 |
| 요약·지갑 총액 | 큰 글씨와 긴 숫자 | 공통 `ValueText` 또는 동일한 줄바꿈 규칙 |
| 거래 평가액·실현 손익 | 줄바꿈 금지와 오른쪽 고정 열 | 금액 줄바꿈 및 좁은 화면의 행 재배치 |
| 지갑 자산 목록 | 아이콘·이름·금액·버튼 폭의 합이 화면보다 큼 | 내용 폭에 따른 줄바꿈, 전체 금액 표시 |
| 증명서 DID·해시 | 복사 버튼과 값의 flex 최소 폭 | 최소 폭 해제, 복사 불가 시 전체 값 줄바꿈 |

금액의 계산·반올림 규칙은 변경하지 않습니다. 값을 임의로 축약하거나 숨기지 않습니다.
주소 축약과 전체 값 복사는 기존 동작을 유지합니다.

## 재현 가능한 브라우저 점검

```sh
pnpm test:layout
# 출력 파일을 지정하려면:
node scripts/check-value-layout.mjs /tmp/verawallet-layout
```

실제 React 컴포넌트를 렌더링하고 현재 Tailwind CSS를 생성한 뒤 Chromium에서 검사합니다.
운영 계정·API·데이터는 사용하지 않습니다. 결과 JSON과 실패 화면 캡처 경로가 출력되며,
넘침이 하나라도 있으면 종료 코드 1을 반환합니다.

- 폭: 320, 375, 393, 430, 768px
- 기본 글자 크기 및 200% 확대
- 0원, 일반 금액, `₩24,030,048,573`, 음수, 30자리 금액
- EVM 주소, 180자 DID, 거래 해시
- 리포트 요약·상세, 요약 카드, 거래 행, 지갑 포트폴리오, VC 검증 결과, 복사 불가 상태의 주소 표시

검사는 요소의 `scrollWidth/clientWidth`와 `data-layout-value` 텍스트의 실제 좌표를
상위 컨테이너 경계와 비교합니다. 일부러 깨뜨린 컨테이너를 탐지하는 검증도 포함합니다.
아이콘 장식, 접근성 전용 텍스트, 명시적인 축약 및 가로 스크롤 영역은 구분합니다.

이는 정적 컴포넌트 레이아웃 검사입니다. 모든 로그인 화면·모달·표·실제 데이터·브라우저를
자동으로 검사한다는 뜻은 아닙니다. 새 표시 구조는 fixture에 추가하고, 표시 값은
`ValueText` 또는 `data-layout-value`를 사용하면 컨테이너 경계 검사에 포함됩니다.
